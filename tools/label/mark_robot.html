MIRLT · Mark the robot 

Which stretch?

Each stretch is a piece of a recorded session where the tracker lost a robot. You mark that robot on one picture a second. The page downloads only the stretch you pick (about 100 MB) and keeps your place if you stop.

Size check (the camera's scale)

Fit four corners to something of known size; the page measures it through the floor calibration. If the calibration is right it measures its real size everywhere on the board.

Keys and how to mark
Enter / SpaceConfirm: the ring is on the robot
dragslide the ring (anywhere on the picture)
click / tapput the ring there
arrow keysnudge 1 pixel (Shift: 5)
Nnot visible
Wnot sure which robot (ring on your best guess)
Sskip
Zundo the last mark
Pplay the second before
[   ]previous / next picture
+   −   0zoom in / out / whole picture
Ccentre the view on the ring
Fsize check: four corner handles on this picture
in the size checkdrag a corner (or inside: all four); Tab: next corner; arrows: a quarter pixel (Shift: 1); Enter: save the fit; R: start again; Esc: done

Put the ring's centre on the centre of the robot itself: its body, not the bright glow its lights throw on the floor next to it. The ring is a robot's size, so a good mark has the ring around the robot's top edge evenly.
