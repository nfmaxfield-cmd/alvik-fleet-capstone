# Notes

Shared working notes for the MIRLT / Alvik project. Nick and Jay-Sun decided on 12 Nov 2026 that all notes can be public, so they live here in the main repo instead of a separate private repo.

- `nick/`: Nick's notes.
- `jay-sun/`: Jay-Sun's notes.

One note per file, named `YYYY-MM-DD-short-topic.md`, so they sort by date.

## Adding a note from the GitHub website (no setup needed)

1. Open https://github.com/nfmaxfield-cmd/alvik-fleet-capstone/tree/main/docs/notes in a browser and click your folder (`nick` or `jay-sun`).
2. Click **Add file**, then **Create new file**.
3. Type the file name, for example `2026-11-12-camera-moved.md`.
4. Type the note in the big box.
5. Click **Commit changes...**, then **Commit changes** again. The note is saved and visible to everyone.

Jay-Sun needs to be added as a collaborator to save notes directly (Nick: the repo's **Settings**, then **Collaborators**, then **Add people**, then `jaysunrutledge7`). Without that, GitHub offers to save the note as a "pull request" for Nick to accept instead.

## What doesn't go here

Raw RFID reads stay out of this public repo until Jay-Sun says otherwise (standing rule from 10 Nov).
